# Disk Space Map · 磁盘空间地图

A local-first Windows disk space visualizer: treemap browsing, global filename search, safe smart cleanup, and file/folder migration. Everything runs on your own machine.

本地优先的 Windows 磁盘空间可视化工具：方块树状图、全盘文件搜索、智能清理缓存/大文件，以及文件迁移。所有数据只在本机处理。

## 功能

- **磁盘地图**：用方块树状图展示 C: / D: / E: 等本地磁盘的目录占用，单击进入子目录。
- **全局文件搜索**：按文件名或部分文件名模糊搜索全部磁盘或当前磁盘，支持 `Ctrl + K`。
- **智能清理**：扫描临时文件、浏览器缓存、开发工具缓存、崩溃转储和可自定义阈值的大文件；缓存默认勾选，大文件默认不勾选。
- **二次确认**：执行删除前必须勾选确认，删除永久生效、不会进入回收站。
- **文件迁移**：右键文件夹或文件即可移动到其他磁盘/文件夹；同盘瞬时移动，跨盘复制校验后再删除源。
- **资源管理器联动**：一键打开当前目录，或在资源管理器中定位文件。
- **完全本地**：本地 HTTP 服务只监听 `127.0.0.1`，不依赖云服务，不上传数据。

## 环境要求

- Windows 10 / 11
- Python 3.10 及以上
- 无第三方 Python 依赖

## 下载与运行

### 方式一：下载 ZIP

1. 点击仓库右上角 **Code → Download ZIP** 并解压。
2. 双击 `start.bat`。
3. 浏览器会自动打开；首次打开某个磁盘时会建立索引。

### 方式二：Git clone

```bat
git clone https://github.com/liuxing5/disk-space-map.git
cd disk-space-map
start.bat
```

如果 `start.bat` 找不到 Python，请先安装 Python 3.10+ 并勾选 **Add Python to PATH**。

### 可选：创建桌面快捷方式

右键 `install-shortcut.ps1`，选择“使用 PowerShell 运行”。脚本会在桌面创建「磁盘空间地图」快捷方式。

如果系统限制执行脚本，可以在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-shortcut.ps1
```

## 使用

| 操作 | 效果 |
| --- | --- |
| 单击方块 | 进入对应文件夹 |
| 悬停方块右上角 `↗` | 在资源管理器中打开 |
| 右键文件夹 / 文件 | 移动到其他位置、打开或复制路径 |
| 右上角「搜索文件」/ `Ctrl + K` | 全盘文件名搜索 |
| 右上角「智能清理」 | 扫描缓存、临时文件和大文件 |
| 顶部磁盘卡片 | 切换磁盘 |
| 「刷新」 | 强制重新扫描当前磁盘 |
| `Alt + ←` / `Backspace` | 返回上一级 |

### 文件搜索

搜索基于本地 SQLite FTS5 索引，支持文件名任意连续片段，例如 `微信`、`.mp4`、`report`。结果可以定位到资源管理器，也可以直接移动。

索引来自磁盘扫描；如果刚新增了大量文件，先刷新对应磁盘。

### 智能清理

清理范围：

- 用户临时目录、Windows 临时目录
- Edge / Chrome / Firefox 缓存
- pip / npm / pnpm / Yarn / uv 缓存
- 崩溃转储、着色器缓存等
- 超过 200 MB / 500 MB / 1 GB / 2 GB 的大文件（阈值可切换）

安全规则：

- 缓存默认勾选；**大文件默认不勾选**。
- 点击“删除选中”后，还要勾选“我已确认这些内容不再需要”，才会执行。
- **永久删除，不进入回收站**；正在使用的文件会跳过，并在结果中显示。
- 大文件候选会排除系统/程序目录、`AppData`、`.git`、`node_modules`、`site-packages`、虚拟机磁盘（`.vhdx` / `.vmdk` 等）、程序库和数据库文件，避免误删不可恢复的运行数据。
- 清理完成后会自动刷新相关磁盘索引。

### 文件迁移

- 同盘移动使用原子重命名，瞬间完成。
- 跨盘移动先复制并校验，成功后才删除源。
- 目标空间不足会提前拒绝；同名项目自动改名为 `名称 (1)`。
- 支持取消；取消会清理目标位置已复制的内容，源文件不受影响。
- 源文件删除失败时会保留完整目标副本并提示。
- 系统目录、程序目录、回收站、Junction/云占位文件和程序自身目录不会被迁移。
- 迁移记录写入 `data/moves.log`。

## 数据与隐私

- 服务只绑定 `127.0.0.1`，不监听公网。
- 所有读取、索引、迁移和删除都在本机执行；没有遥测、没有上传。
- 索引存放在程序目录的 `data/` 下，每个磁盘保留最新 1 份缓存。
- 索引包含目录、文件名和全文搜索数据，大小取决于文件数量；删除 `data/` 后下次会重新扫描。
- 扫描会跳过 Junction、符号链接、云占位和无权限访问的位置，所以“已扫描大小”可能略小于系统显示的“已用空间”。

## 项目结构

```text
app.py                本地 HTTP 服务和 API
scanner.py            磁盘扫描与 SQLite/FTS5 索引
mover.py              文件/文件夹迁移引擎
cleaner.py            缓存与大文件扫描/删除引擎
static/               前端页面
assets/               应用图标
docs/                 文档截图
data/                 运行时索引与日志（不提交到 Git）
start.bat             启动入口
install-shortcut.ps1  创建桌面快捷方式
```

## 开发

```bat
python app.py --no-browser
```

日志位于 `data/server.log`。

## 已知限制

- 仅支持 Windows（依赖 Windows 盘符、文件属性和 Explorer）。
- 非管理员运行时，部分系统目录会显示为无法访问或被跳过。
- 大文件索引和全文索引会占用数百 MB 磁盘空间，具体取决于文件数量。
- 搜索索引是扫描时的快照，不实时监听文件系统变化；需要手动或重新打开页面刷新。
- 清理中的“大文件”需要用户自行判断；删除不可恢复，重要数据请先备份。
